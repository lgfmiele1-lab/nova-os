# NOVA OS ⚡

NOVA OS é um ambiente operacional experimental executado diretamente no navegador, construído com tecnologias web modernas (HTML5, CSS3 e JavaScript).

## 🚀 Versão Atual
* **Alpha 0.1:** Estrutura base do desktop, barra de tarefas com relógio em tempo real, menu iniciar interativo e sistema básico de janelas.

## 🛠️ Tecnologias
* HTML5
* CSS3 (Tema Cyberpunk/Futurista com Azul Neon)
* JavaScript Moderno (Vanilla)
